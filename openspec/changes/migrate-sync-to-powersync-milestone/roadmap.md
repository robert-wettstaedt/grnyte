# Zero to PowerSync: the whole sequence

Decided 2026-11-07. This change is the milestone. Each later release gets its own OpenSpec change when its gate is passed; this file is the one place the sequence, scopes and gates are written down. Claude-days, the user reviewing and testing on devices.

| Step                                  | Scope                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | Gate to start                              | Gate to finish                                                                                             | Days    |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------ | ---------------------------------------------------------------------------------------------------------- | ------- |
| **Milestone** (this change)           | PowerSync service on the VPS, region streams, client schema, sync shell, guidebook screens on PowerSync. Feed, inbox, comments and every write stay on Zero on the branch. Nothing deploys.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | done                                       | Rules 1, 2 and 8 on the user's iPhone no worse than today's Zero build; offline guidebook works. Go/no-go. | 7 to 10 |
| **R1**                                | Writes as awaited POSTs to `/api/sync/mutate` (a second route file over the existing mutate handler; `/api/zero/mutate` kept for zero-cache). Feed, inbox, comments, EventMeta and entity logs as server reads (remote queries over the drizzle tree the push digest uses; the "N new" pill from a per-region counter). Tests and ratchets, the stream-predicate security review, review loops. Cutover: one release with zero-cache, the CVR database, the `_zero_*` publications and slot, `zero_0` and `PUBLIC_ZERO_URL` all left in place, so open tabs keep syncing and a Vercel rollback to the Zero build works. Deploy order: publication, PowerSync beside Zero, app. | Milestone go                               | Production on PowerSync, no Zero on the client, one release of overlap running.                            | 6 to 9  |
| **R2**                                | Local recent-events window (`feed_recent` flag kept by a trigger on events and changes, N=100 per region and category), notifications stream and live unread count, thread stream for comments (predicate fixed for deleted roots with live replies), reactions on cards. New mutate implementation under `/api/sync/mutate`: the server mutator registry called directly with its own idempotency table.                                                                                                                                                                                                                                                                      | R1 shipped and stable for a week           | Feed and inbox offline, comments live within 1 s.                                                          | 5 to 8  |
| **R3**                                | Zero removal: zero-cache and `zero-cvr-prod` from the compose, the nginx block, DNS and cert for `zero.grnyte.rocks`, the 10 `ZERO_*` secrets, the `_zero_*` publications and the `zero_0_a` slot, the `zero_0` schema, `/api/zero/mutate`, `src/lib/zero/*` and the 33 files importing it, the generated Zero schema and `generate:zero`, `@rocicorp/zero`, `zero-svelte`, `drizzle-zero`, the `ci/shim.sql` block, `e2e/support.ts`'s zero-cache check, the skills and AGENTS.md lines that teach Zero, the `$lib/zero/resource.svelte` move to `$lib/sync/`.                                                                                                                | One release after R1 (the deploy-gap rule) | No Zero anywhere; `lint:unused` green.                                                                     | 2       |
| **Offline writes** (own PR, after R2) | The intent queue (insert-only mutations table, per-device contiguous ids, refusal surfacing, placeholder rows), ascent logging offline first, then toggles. PowerSync's attachment queue for media later.                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | R2 shipped                                 | Airplane-mode ascent with a photo reaches the server on reconnect.                                         | 5 to 8  |

Settled across all steps: MongoDB bucket storage on the VPS at `sync.grnyte.rocks`; whole regions on every device, desktop included; never two engines in a shipped build; mappers unchanged behind the row shim until R3; `queries.ts` and the generated Zero schema kept as type-only sources until R3; the Expo app starts after R1 on the final engine.
