## Round 1

- Snapshot: frozen copy at `add-social-sign-in-r1` (the worktree guard refuses the temp-index commit recipe); code at develop `7e25d347`. Prerequisite changes (read from `openspec/changes/`): `migrate-supabase-keys`, `harden-auth-codes`.

- Reader paraphrase, what this proposes: "grnyte adds \"Continue with Apple\" and \"Continue with Google\" to the web sign-in and create-account screens. grnyte's own server runs the OAuth code flow with `openid-client` (PKCE, `state`, a hashed nonce), keeps one sign-in in a sealed `SameSite=Lax` single-use 10-minute cookie, and hands the verified ID token to GoTrue's `signInWithIdToken`; Apple's cross-site `form_post` is answered with a 303 to a same-origin GET. A new \"Sign-in methods\" settings screen links and unlinks providers behind re-authentication, Apple-linked accounts get \"Confirm with Apple\" as a re-auth alternative that also revokes grnyte's Apple authorization on account deletion and Apple unlink, and a provider never joins a confirmed account unless it owns the address's domain."
- Reader paraphrase, how the existing system works per this plan: "After change 1 (`harden-auth-codes`), sensitive actions need a 5-minute \"grant\" bound to account, session, action and target, produced by mailed 6-digit codes through `ReauthStep`/`CodeEntry` (which has an `alternatives` slot); a trigger on `auth.identities` refuses identity inserts and deletes unless the account is new or unconfirmed, the identity is GoTrue's own email identity, the provider owns the address's domain, or a bound `identity.link`/`identity.unlink` grant exists. `migrate-supabase-keys` provides `supabaseAuthServer`, an allowlisted secret-key auth client that forwards the client IP, and change 1 adds `supabaseAuthServerAs(event, VerifiedToken)` for calls made as the user. `authGuard` loads the cookie session on every request, bounces signed-in visitors off `/auth/*` except emailed-link paths, and sends profile-less accounts to `/auth/profile?next=`; a cross-site guard refuses cookie-carrying non-GET requests unless same-origin, with `POST /auth/callback/apple` already exempt."
