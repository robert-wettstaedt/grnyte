## How the tests are written

As in 1177 (its design D16): a test comes before the code it needs and is seen red first; fakes sit at the edges only (the PowerSync database, `readQuery`, `isOnline`, `document.visibilityState`); no test asks how often something of ours was called, except where the fake edge is the observer (a request `readQuery` received). Server tests run through `ci/local.sh` only.
