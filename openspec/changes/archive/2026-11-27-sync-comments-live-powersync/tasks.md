## How the tests are written

As in 1177 and 1180: a test comes before the code it needs and is seen red first; fakes sit at the edges only (`toggleReaction`, the global user); no test asks how often something of ours was called. Server tests run through `ci/local.sh` only; this change adds none.

Tests sit at three seams, and only there: `withOwnEmoji` (a pure function), `createReactionToggle`'s public face (`chips`, `toggle`, `busy`, with `toggleReaction` faked at `reaction/writes.ts`), and `toZeroRow` for a `content_reports` row. One test, then the code it needs, then the next (vertical slices). The marker wiring and the report twin are checked by svelte-check, `twins.test.ts` and the drive.
